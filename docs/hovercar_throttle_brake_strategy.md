# Hovercar 油门 / 刹车 / 倒车策略说明

## 1. 目标

本策略的目标是：
- 油门释放时不要直接把输出打到 0，避免“突然失力”导致的抖动；
- 刹车要像真实物理制动一样，踩得更深时产生更强的反向扭矩；
- 倒车只在满足条件时才进入，且速度受限，避免危险的反向加速。

## 2. 输入与状态

当前控制逻辑在悬浮车模式下会同时关注以下状态：
- 油门输入：前进/加速命令；
- 刹车踏板输入：用于生成制动目标；
- 当前车速：用于判断正向、反向和低速区；
- 双击检测状态：用于在低速时允许短暂的倒车触发。

## 3. 油门策略

- 正常前进时，油门命令由当前输入和限速器共同决定；
- 释放油门时使用较慢的下降速率，避免“拔掉油门后立刻回零”；
- 低速时，命令会先通过滤波器和速率限制器，避免突变。

## 4. 刹车策略

- 刹车踏板被读取后，先转换成一个“制动目标”，而不是直接把命令硬改成反向输出；
- 制动目标会按踏板力度和当前车速进行缩放；
- 低速区和高速区使用不同的增益，保证低速起步时制动更平顺；
- 制动目标会经过一个缓慢上升/下降的斜坡，避免瞬间翻转。

### 4.1 关键参数

- BRAKE_PEDAL_THRESHOLD：刹车踏板触发阈值；
- BRAKE_MIN_SPEED_RPM：低速时制动增益开始生效的最低速度；
- BRAKE_SMOOTH_ZONE_RPM：制动增益从 0 线性过渡到满量程的区间；
- BRAKE_RAMP_STEP：制动目标的斜坡步长；
- BRAKE_MAX_LIMIT：制动目标的最大幅值。

## 5. 倒车策略

- 只有在低速区且检测到双击刹车时，才允许进入“倒车请求”；
- 倒车请求只有在存在实际油门输入时才会生成反向驱动；无输入时会快速回零，不会持续后退；
- 倒车时依然经过同样的滤波和限幅流程，避免出现突兀的方向反转。

## 6. 左右轮方向说明

左右轮方向之所以要相反，是因为车轮需要通过“相反的转向”来产生前进或后退的推进力。

在当前混控逻辑里：
- 右轮命令和左轮命令由同一个速度命令与转向命令混合得到；
- 正常直线前进时，左右轮需要以相反的电机极性输出，才能让车体整体朝同一个方向移动；
- 方向反转时，控制逻辑会根据实际电机方向和方向反转宏定义，保证速度正负号和车轮实际转向一致。

## 7. 串口调试输出

串口输出中新增了以下字段，便于实时观察策略状态：
- rev：是否触发了倒车请求；
- tap：双击检测是否成立；
- dir：当前运动方向；
- br：当前踏板输入幅值；
- bt：当前制动目标；
- fbc：滤波后制动命令；
- thr：当前实际用于限速器的油门/制动目标。

通过这些字段，可以快速判断当前是不是进入了倒车、是否产生了制动、以及制动目标是否被正确限制。
